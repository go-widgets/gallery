go-widgets — isometric diagram editor

Live wasm demo of go-widgets/toolkit's IsoDiagram + collaborative CRDT store.

A fully interactive isometric editor running entirely in your browser — no server. Drag an icon from the docked palette onto a canvas to drop a node at the exact ground tile; use the mode bar to Select, place a Node, Connect two nodes, draw a Zone or add Text; Undo/Redo/Delete; show/hide a Layer; Zoom in/out; left-drag empty ground to pan; right-click any element for its context menu. The two canvases are separate CRDT replicas (Site A / Site B): every edit auto-Syncs both ways, so a change in one appears in the other — live collaboration with no backend. Cross-boundary state flows through go-widgets/mvvm Observables. Press ⛶ Full window (or double-click the canvas) to expand; Esc exits.
