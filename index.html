Live wasm demo of go-widgets/toolkit.

A live, interactive dashboard exercising the whole go-widgets/toolkit — every widget family in its own labelled slot. It's a demonstrator you drive: drag Kanban cards between columns and Gantt bars to reschedule; right-click any Kanban card, Gantt task, Agenda day, list item, table row or tree node to edit it (move, duplicate, delete, add…); switch the Agenda between Week / Month / Quarter / Year and click an empty day to add an event; recolour the whole scene from the theme switcher. Interactive state flows through go-widgets/mvvm (Observable / Command / ObservableList). Click a menu name for its popover; press ⛶ Full window (or double-click the canvas) to expand it to fill the browser window — Esc exits.
